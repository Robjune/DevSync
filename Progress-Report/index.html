STATUS SUMMARY

The group focused on developing the frontend and interactive features of DevSync, a collaborative developer portfolio for CPE-201 Group 3. The website currently includes the Home, About, Team, Projects, and Contact sections.

HTML and CSS were used to build and design the interface, while JavaScript was implemented for contact form processing and message storage. A separate messages page was also created to view and manage submitted messages.
